# تشغيل FindIt مع AI حقيقي

1. افتحي فولدر FindIt-Community-Edition الداخلي في VS Code (لازم تلاقي package.json).
2. افتحي Terminal واحدة، واكتبي الأوامر التالية بنفس الترتيب:

```powershell
$env:OPENAI_API_KEY = Read-Host "Enter your API key"
$env:PORT = 3003
npm.cmd start
```

3. افتحي http://localhost:3003/ للموقع، أو http://localhost:3003/admin.html للأدمن.
4. اضغطي على شعار FindIt في لوحة الأدمن للعودة للصفحة الرئيسية.
5. افتحي مساعد FindIt من الزر العائم وجربي سؤالًا.

**لو المفتاح غير موجود:** الشات هيقول إنه غير مُعد. إنشاء حساب Admin لا يفعّل AI.
**لو ظهر 401/429 أو AI unavailable:** تأكدي من صلاحية المفتاح وإعدادات الفوترة والاتصال.
**لو ظهر EADDRINUSE:** Port 3003 مشغول؛ اختاري رقمًا متاحًا وغيري الرابط بنفس الرقم.
**لو نقلتي المشروع لفولدر جديد:** حساب Admin القديم لا ينتقل إلا لو نقلتي قاعدة البيانات. احتفظي بنسخة احتياطية من data/db.json.

لا تضعي مفتاح API داخل public أو GitHub، ولا ترسليه في المحادثة. اشتراك ChatGPT منفصل عن API.
